# Automation

## Overview

This folder documents my journey into IT, cloud and security automation.

I am developing my automation skills to learn how repetitive IT and cloud tasks can be performed through scripts and automated processes rather than relying entirely on manual administration.

My goal is to progress from basic scripting into Azure automation, Infrastructure as Code, CI/CD, and eventually cloud security automation.

---

## Why I Want to Learn Automation

As I work toward a career in cloud engineering and cloud security, I want to develop the ability to manage environments efficiently and consistently.

In IT and cloud environments, administrators may repeatedly perform tasks such as:

- Checking system services
- Monitoring system health
- Reviewing logs
- Deploying infrastructure
- Managing cloud resources
- Identifying issues
- Performing repetitive administrative tasks

Automation can make these processes:

- Faster
- More consistent
- Repeatable
- Less prone to human error
- Easier to scale

I also want to understand how automation can be applied to cloud infrastructure and security operations.
